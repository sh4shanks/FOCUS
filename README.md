## 🧠 Mission Brief

**FOCUS** is an intelligent student support and study-planning platform designed to solve a simple but important problem:

> **“I have so much to study. What should I do right now?”**

Instead of forcing students to manually figure out priorities, FOCUS brings together:

* 📚 Syllabus progress
* 📝 Assignments
* 📅 Exams
* 🔁 Revision schedules
* ⏱️ Available study time
* 📊 Learning progress
* 🧠 Practice performance

and transforms them into actionable study decisions.

```text
┌──────────────────────────────────────────────┐
│  SYLLABUS:          68% COMPLETE             │
│  ASSIGNMENTS:       4 PENDING                │
│  REVISION:          3 TOPICS DUE             │
│  NEXT EXAM:         12 DAYS                  │
│  AVAILABLE TIME:    45 MINUTES               │
│                                              │
│  FOCUS RECOMMENDS:                            │
│  → Physics: Electromagnetic Induction        │
│  → 20 min Problem Practice                   │
│  → 10 min Active Recall                      │
│  → 5 min Confidence Check                    │
└──────────────────────────────────────────────┘
```

FOCUS isn't designed to make students study more.

It's designed to help them **study smarter, with less uncertainty.**

The signature FOCUS feature.


> **Never waste your first 10 minutes deciding what to study.**

# 🧪 Practice Mode

Practice Mode turns the student's syllabus into an interactive practice environment.

### Configure a session:

| Option           | Choices                        |
| ---------------- | ------------------------------ |
| 📚 Subject       | Existing FOCUS subjects        |
| 📖 Topic         | Existing syllabus topics       |
| 🎚️ Difficulty   | Easy / Medium / Hard           |
| 🔢 Questions     | 5 / 10 / 15 / Custom           |
| 🧩 Question Type | MCQ / Numerical / Short Answer |

Students receive questions one at a time with:

* Instant answer feedback
* Explanations
* Progress tracking
* Correct/incorrect analysis
* Final score
* Weak-topic detection

At the end of a session:

```text
┌──────────────────────────────────────────────┐
│             PRACTICE RESULTS                 │
├──────────────────────────────────────────────┤
│                                              │
│              8 / 10                         │
│                80%                           │
│                                              │
│  Strong:     Current Electricity             │
│  Review:     Kirchhoff's Laws                │
│  Review:     Wheatstone Bridge               │
│                                              │
│  → Add weak topics to Revision               │
│  → Practice Again                            │
└──────────────────────────────────────────────┘
```

Weak topics can automatically flow into the existing **Revision System**.

```text

        ↓

REDISTRIBUTES WORKLOAD

        ↓

UPDATED PLAN

Wednesday +15 min
Thursday  +10 min
```

The goal is to keep the student moving without creating unnecessary overload.

# 🏗️ Architecture Philosophy

FOCUS is designed as a **student operating system with an intelligent study copilot**.

It is not simply:

```text
"ChatGPT + a dashboard"
```

Instead:

```text
Student Data
     ↓
FOCUS Intelligence
     ↓
Prioritization
     ↓
Action
     ↓
Practice
     ↓
Revision
     ↓
Progress
     ↓
Better Recommendations
```

The AI layer is integrated with the student's existing academic workflow instead of replacing it.

---

# 🔐 Privacy & Security

FOCUS is designed with student privacy in mind.

The application should:

* Avoid exposing API keys in client-side code
* Keep AI provider logic behind a secure server-side endpoint when required
* Send only relevant academic context to AI services
* Avoid unnecessary personal information
* Keep local data under the student's control where possible
